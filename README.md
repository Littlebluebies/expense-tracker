# 💸 บันทึกรายรับ-รายจ่าย

เว็บแอปจดรายรับ-รายจ่ายรายเดือน ตั้งงบได้ทั้งงบรวมและงบรายหมวด มีกราฟสรุป ลงรายการประจำให้อัตโนมัติ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## ทำอะไรได้บ้าง

- **จดรายรับ-รายจ่าย** เลือกหมวด เลือกวันที่ย้อนหลังได้ และเขียนบันทึกสั้นๆ ได้
- **ตั้งงบรายเดือน** ใช้ค่าเดียวทุกเดือน หรือตั้งแยกเป็นเดือนๆ ก็ได้
- **ตั้งงบรายหมวด** เช่น อาหาร 6,000 ฿ เพื่อดูว่าเงินหมดไปกับอะไร
- **รายการประจำ** เช่น ค่าเช่า ค่าเน็ต เงินเดือน แอปจะลงให้เองทุกเดือน
- **เทียบกับเดือนก่อน** บอกว่าใช้มากขึ้นหรือน้อยลง และหมวดไหนเปลี่ยนมากที่สุด
- **กราฟ** สัดส่วนรายจ่ายตามหมวด และรายจ่ายย้อนหลัง 6 เดือนเทียบกับงบ
- **จดด่วน** ปุ่มลัดของรายการที่จดบ่อย กดครั้งเดียวจบ และกด "เลิกทำ" ได้ทุกครั้งที่เพิ่มหรือลบ
- **ค้นหาและส่งออก** ค้นรายการได้ และดาวน์โหลดเป็นไฟล์ CSV เปิดใน Excel ได้
- **ใช้ออฟไลน์ได้** ข้อมูลจะซิงค์เองเมื่อกลับมาออนไลน์
- **ติดตั้งบนมือถือได้** เหมือนแอปทั่วไป และมีโหมดมืด
- **ตั้งค่าบัญชี** เปลี่ยนชื่อ เปลี่ยนรหัสผ่าน ยืนยันอีเมล ส่งออกข้อมูลทั้งหมด และลบบัญชีได้

## วิธีใช้งาน

### 1. สมัครสมาชิกและเข้าสู่ระบบ

สมัครด้วยชื่อผู้ใช้ อีเมล และรหัสผ่านอย่างน้อย 6 ตัว หลังสมัครแอปจะส่ง **อีเมลยืนยัน** ไปให้ กดลิงก์ในอีเมลเพื่อยืนยันว่าเป็นเจ้าของอีเมลจริง ถ้าลืมรหัสผ่าน กด **"ลืมรหัสผ่าน?"** ที่หน้าเข้าสู่ระบบ แล้วระบบจะส่งลิงก์รีเซ็ตไปที่อีเมล

### 2. เลือกเดือนที่ต้องการดู

ปุ่ม **‹ ›** ด้านบนใช้เลื่อนไปเดือนก่อนหน้าหรือถัดไป ทุกอย่างในหน้าจอ (ยอดคงเหลือ งบ กราฟ รายการ) จะแสดงเฉพาะเดือนที่เลือก ถ้าอยากกลับมาเดือนปัจจุบัน กด **"กลับไปเดือนปัจจุบัน"**

### 3. ตั้งงบประมาณของเดือน

ในกล่อง **🎯 งบประมาณ** กด **"ตั้งงบ"** แล้วใส่จำนวนเงิน

- ติ๊ก **"ใช้เป็นงบเริ่มต้นทุกเดือน"** ถ้าอยากให้ทุกเดือนใช้งบเท่ากัน
- ไม่ติ๊ก ถ้าจะตั้งงบเฉพาะเดือนนี้ เช่น เดือนที่มีค่าใช้จ่ายพิเศษ

แถบสีจะบอกสถานะ ✅ อยู่ในงบ, ⚠️ ใช้ไปเกิน 80%, ⛔ เกินงบแล้ว ส่วนในเดือนปัจจุบัน แอปจะบอกด้วยว่าเหลือใช้ได้อีก **วันละเท่าไหร่**

### 4. จดรายการ

ในกล่อง **➕ เพิ่มรายการ**

1. เลือก **รายจ่าย** หรือ **รายรับ**
2. ใส่จำนวนเงิน (ใส่ทศนิยมได้ เช่น 45.50)
3. เลือกหมวด และเปลี่ยนวันที่ถ้าเป็นรายการย้อนหลัง
4. ใส่บันทึกเพิ่มเติมหรือไม่ใส่ก็ได้ เช่น "ข้าวกลางวัน"
5. กด **เพิ่มรายการ**

> 💡 หลังกดเพิ่ม แอปจะจำประเภท หมวด และวันที่ไว้ให้ จดหลายรายการติดกันได้เร็วขึ้น

**⚡ จดด่วน:** รายการที่จดซ้ำตั้งแต่ 2 ครั้งขึ้นไปใน 60 วันล่าสุด (หมวด จำนวนเงิน และบันทึกเหมือนกัน เช่น กาแฟ 60 ฿) จะขึ้นเป็นปุ่มลัดด้านบนฟอร์ม กดครั้งเดียวก็ลงรายการของวันนี้ทันที

**แก้ไขหรือลบ:** ในรายการด้านล่าง กด ✏️ แล้วข้อมูลจะขึ้นในฟอร์มให้แก้ หรือกด 🗑️ เพื่อลบ

> ↩️ ทุกครั้งที่เพิ่มหรือลบรายการ จะมีปุ่ม **"เลิกทำ"** ขึ้นที่ด้านล่างจอประมาณ 5 วินาที กดผิดก็กดเลิกทำได้เลย

### 5. ตั้งงบรายหมวด

ในกล่อง **🗂️ งบรายหมวด** กด **"ตั้งงบหมวด"** แล้วใส่งบให้หมวดที่อยากคุม หมวดที่เว้นว่างไว้จะไม่จำกัดงบ งบรายหมวดใช้ค่าเดียวกันทุกเดือน

แต่ละหมวดจะมีแถบบอกว่าใช้ไปเท่าไหร่และเหลืออีกเท่าไหร่ หมวดที่ใกล้เต็มหรือเกินงบจะอยู่บนสุด

### 6. ตั้งรายการประจำ

สำหรับรายการที่เกิดขึ้นทุกเดือน เช่น ค่าเช่าห้อง ค่าโทรศัพท์ Netflix หรือเงินเดือน

1. เปิดกล่อง **🔁 รายการประจำ** แล้วกด **"+ เพิ่มรายการประจำ"**
2. ใส่ชื่อรายการ จำนวนเงิน หมวด และ **วันที่ของทุกเดือน**
3. ถ้าเดือนนี้จดรายการนี้เองไปแล้ว ให้ติ๊ก **"เริ่มเดือนหน้า"** เพื่อไม่ให้ลงซ้ำ

พอถึงวันที่กำหนด แอปจะลงรายการให้อัตโนมัติตอนเปิดแอป (รายการที่ลงอัตโนมัติมีไอคอน 🔁)

- **ไม่ได้เปิดแอปหลายเดือน** แอปจะลงย้อนหลังให้ครบ สูงสุด 12 เดือน
- **ตั้งวันที่ 29–31** เดือนที่มีไม่ถึงวันนั้นจะลงวันสุดท้ายของเดือนแทน
- **⏸ หยุดชั่วคราว** เมื่อกดเปิดใช้ใหม่ แอปจะไม่ลงเดือนที่หยุดไว้ย้อนหลัง
- **✏️ แก้ไข** มีผลกับเดือนถัดไปเท่านั้น รายการที่ลงไปแล้วจะไม่เปลี่ยน
- **🗑️ ลบ** รายการที่เคยลงไปแล้วยังอยู่ครบ

### 7. ดูกราฟและสรุป

- **📌 เทียบกับเดือนก่อน** บอกว่ารายจ่ายมากขึ้น ▲ หรือน้อยลง ▼ กี่บาทและกี่เปอร์เซ็นต์ พร้อม 3 หมวดที่เปลี่ยนมากที่สุด ถ้าเป็นเดือนปัจจุบันที่ยังไม่จบเดือน จะเทียบกับช่วงวันเดียวกันของเดือนก่อน (เช่น วันที่ 1–15 กับ 1–15) ตัวเลขจะได้ไม่เพี้ยน
- **📊 รายจ่ายตามหมวด** บอกว่าแต่ละหมวดใช้ไปเท่าไหร่ และคิดเป็นกี่เปอร์เซ็นต์
- **📈 รายจ่ายรายเดือน** เปรียบเทียบ 6 เดือนล่าสุด เส้นประคืองบของแต่ละเดือน แตะที่แท่งกราฟเพื่อกระโดดไปดูเดือนนั้น

### 8. ค้นหาและส่งออกข้อมูล

ในกล่อง **🧾 รายการ**

- กรองได้ว่าจะดูทั้งหมด เฉพาะรายจ่าย หรือเฉพาะรายรับ
- ค้นหาได้จากชื่อหมวด บันทึก หรือจำนวนเงิน
- กด **⬇️ CSV** เพื่อดาวน์โหลดรายการของเดือนนั้น เปิดใน Excel หรือ Google Sheets ได้

### 9. ใช้งานตอนไม่มีอินเทอร์เน็ต

จดรายการได้ตามปกติ ระหว่างนั้นจะมีแถบ **📴 ออฟไลน์อยู่** ขึ้นด้านบน แล้วข้อมูลจะซิงค์ขึ้นระบบเองเมื่อกลับมาออนไลน์

> ⚠️ ต้องเคยเปิดแอปตอนออนไลน์ในเครื่องนั้นมาก่อนอย่างน้อย 1 ครั้ง

### 10. ติดตั้งเป็นแอปบนมือถือ

- **Android (Chrome):** เปิดเว็บ แล้วกดเมนู ⋮ → **"ติดตั้งแอป"** หรือ **"เพิ่มลงในหน้าจอหลัก"**
- **iPhone (Safari):** เปิดเว็บ แล้วกดปุ่มแชร์ ⬆️ → **"เพิ่มไปยังหน้าจอโฮม"**

ปุ่ม 🌙 / ☀️ มุมขวาบนใช้สลับโหมดมืดหรือสว่าง แอปจะจำค่าที่เลือกไว้

### 11. ตั้งค่าบัญชี

กดปุ่ม **⚙️** มุมขวาบน

- **โปรไฟล์** เปลี่ยนชื่อที่แสดง และดูสถานะการยืนยันอีเมล ถ้ายังไม่ได้รับอีเมล กด **"ส่งอีเมลยืนยัน"** อีกครั้ง พอกดลิงก์ในอีเมลแล้ว ให้กลับมากด **"ฉันยืนยันแล้ว"**
- **เปลี่ยนรหัสผ่าน** ต้องใส่รหัสผ่านปัจจุบันก่อน
- **ส่งออกข้อมูลทั้งหมด** ดาวน์โหลดทุกรายการทุกเดือนเป็นไฟล์ CSV
- **ออกจากระบบ**
- **ลบบัญชี** ลบบัญชีและข้อมูลทั้งหมดอย่างถาวร กู้คืนไม่ได้ ต้องใส่รหัสผ่านและพิมพ์คำว่า "ลบบัญชี" เพื่อยืนยัน และต้องต่ออินเทอร์เน็ตอยู่

## สำหรับนักพัฒนา

### เทคโนโลยีที่ใช้

React 19, React Router 7, Bootstrap 5, Chart.js และ Firebase (Authentication + Firestore)

### ติดตั้งและรันบนเครื่อง

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
npm install     # ติดตั้ง dependencies (ครั้งแรกครั้งเดียว)
npm start       # เปิดที่ http://localhost:3000
npm test        # รันเทสต์
npm run build   # สร้างไฟล์สำหรับขึ้นเว็บจริง (โฟลเดอร์ build/)
```

### ตั้งค่า Firebase

1. สร้างโปรเจกต์ที่ [Firebase Console](https://console.firebase.google.com/)
2. เปิด **Authentication** → เปิดใช้วิธีล็อกอินแบบ **Email/Password**
3. สร้าง **Firestore Database**
4. คัดลอกค่า config ของเว็บแอปไปใส่ใน [`src/firebase/config.js`](src/firebase/config.js)
5. **สำคัญ:** คัดลอกเนื้อหาไฟล์ [`firestore.rules`](firestore.rules) ไปวางที่ Firestore → **Rules** แล้วกด **Publish** ไม่อย่างนั้นข้อมูลของผู้ใช้แต่ละคนจะไม่ถูกแยกออกจากกัน

### นำขึ้นเว็บจริง (Vercel)

1. Push โค้ดขึ้น GitHub
2. ไปที่ [vercel.com/new](https://vercel.com/new) แล้วเลือก repo นี้ Vercel จะตรวจเจอว่าเป็น Create React App เอง ไม่ต้องตั้งค่าอะไรเพิ่ม แล้วกด **Deploy**
3. นำโดเมนที่ได้ (เช่น `ชื่อแอป.vercel.app`) ไปเพิ่มที่ Firebase Console → Authentication → Settings → **Authorized domains**

หลังจากนั้น ทุกครั้งที่ push ขึ้น branch `main` Vercel จะ deploy ให้อัตโนมัติ

ไฟล์ [`vercel.json`](vercel.json) ตั้งค่าไว้ให้แล้ว:
- ทุก path ชี้ไปที่ `index.html` รีเฟรชหน้า `/dashboard` แล้วไม่เจอ 404
- `service-worker.js` ไม่ถูกแคช ผู้ใช้จึงได้เวอร์ชันใหม่ทุกครั้งที่อัปเดต
- header ความปลอดภัยพื้นฐาน (กันเว็บอื่นเอาไปฝังใน iframe ฯลฯ)

> ⚠️ Vercel build ด้วย `CI=true` ซึ่งทำให้ ESLint warning กลายเป็น error ควรลอง `npm run build` บนเครื่องก่อน push ทุกครั้ง

> ฟีเจอร์ติดตั้งเป็นแอปบนมือถือทำงานเฉพาะบนเว็บที่ deploy แล้วและเป็น HTTPS ส่วนตอนรัน `npm start` service worker จะถูกปิดไว้

### ความปลอดภัย

ค่า config ใน `src/firebase/config.js` (รวมถึง `apiKey`) **เปิดเผยได้ตามปกติของ Firebase** เพราะอยู่ในโค้ดหน้าเว็บอยู่แล้ว ถ้า GitHub แจ้งเตือนว่าเจอ API key ถือเป็นเรื่องปกติ สิ่งที่ปกป้องข้อมูลจริงๆ คือ

1. **Firestore Rules** ([`firestore.rules`](firestore.rules)) ผู้ใช้แต่ละคนเข้าถึงได้เฉพาะข้อมูลของตัวเอง
2. **จำกัด API key ตามโดเมน** ไปที่ Google Cloud Console → APIs & Services → Credentials → เลือก key → Website restrictions แล้วใส่โดเมนเว็บจริงกับ `http://localhost:3000/*`

### โครงสร้างข้อมูลใน Firestore

| Collection | เก็บอะไร |
|---|---|
| `transactions/{id}` | รายการรับ-จ่าย: `userId`, `type` (`income`/`expense`), `amount`, `category`, `date`, `note`, `recurringId` (ถ้าลงจากรายการประจำ) |
| `budgets/{uid}` | งบของผู้ใช้: `budget` (งบเริ่มต้น), `monthly` (งบเฉพาะเดือน เช่น `{"2026-10": 15000}`), `categories` (งบรายหมวด) |
| `recurring/{id}` | รายการประจำ: `userId`, `type`, `amount`, `category`, `note`, `day`, `startMonth`, `lastPosted`, `active` |
